# Caixa-em-Codigo-C
Projeto desenvolvido em linguagem C para simular a lógica de um caixa eletrônico. O programa recebe o saldo disponível e o valor do saque, realiza validações e calcula a quantidade de notas necessárias (R$ 100, R$ 50, R$ 20, R$ 10 e R$ 5).  com foco no aprendizado de lógica de programação, estruturas condicionais, variáveis e operadores.
