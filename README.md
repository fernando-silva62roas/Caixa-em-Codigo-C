Caixa Eletrônico em Linguagem C
Descrição

Este projeto consiste em um programa de caixa eletrônico desenvolvido em linguagem C. O sistema permite que usuários realizem login utilizando um número de usuário e uma senha.

Funcionalidades
Login de três usuários diferentes (Ana, Bruno e Luis).
Verificação de usuário e senha.
Consulta do saldo disponível.
Realização de saques.
Validação do valor solicitado.
Verificação de saldo insuficiente.
Cálculo automático da quantidade de notas de R$ 100, R$ 50, R$ 20, R$ 10 e R$ 5.
Exibição do saldo atualizado após o saque.
Objetivo

O objetivo do projeto é praticar conceitos básicos da linguagem C, como variáveis, estruturas condicionais (if e else), entrada e saída de dados (scanf e printf) e operadores matemáticos.

Linguagem utilizada
C
Conclusão

O projeto simula o funcionamento básico de um caixa eletrônico, permitindo praticar a lógica de programação e desenvolver conhecimentos fundamentais em linguagem C.
